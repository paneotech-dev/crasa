How it fits together

One platform, three surfaces, one content core

Every surface reads and writes the same content core. The trilingual layer sits inside that core, so a translation entered once appears wherever the content appears. Single Sign-On connects the three existing CRASA systems, so a member logs in once.

Read the green band as content. Anything published, in any language, passes through the trilingual layer, so a French page is the same record as its English original, not a separate copy.
Read the amber band as identity. The Single Sign-On bridge means a committee chair reaches the extranet and the events platform with one credential, and access is revoked in one place.
Read the dark row as surfaces. Each is a distinct interface with its own density and chrome, and all three are built from the one design system in this pack.
Trilingual proof

The same homepage, three times

French runs about 18 percent longer than English, Portuguese about 21 percent. Nothing here is a separate layout: the same components absorb the expansion because headings wrap on a balanced measure, buttons size to their label, and the navigation collapses at the width where the longest language stops fitting.

English sits at the root, so existing links keep working. Slugs are translated per language, and each page emits alternate language links for its published translations only. Switching language keeps you on the same content, not back at the homepage.

How the language layer works

  1. One record, three fields. A publication is a single record with a value per language for each translatable field. A French page is not a copy of the English page, so metadata, files and relationships stay in step automatically.
  2. Interface and content are separate. The interface language comes from the URL. The content language comes from what has been published. A French visitor reading an English-only document sees French chrome and English text, each correctly marked.
  3. Fallback is stated, never silent. Where a field has no translation, the English text is shown with a notice in the reader's language and a lang attribute on the text itself, so screen readers switch voice.
  4. Machine drafts are marked. A machine-translated field is labelled as a draft in the editor and cannot be published as approved copy until a speaker of that language approves it.
  5. Expansion is designed for. No fixed widths on labels or buttons, balanced heading wraps, and navigation that collapses on measured width rather than a device breakpoint.
