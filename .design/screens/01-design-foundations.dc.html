Binding colour rules
  • Green (#1A8C5A) is never used for body text on cream or white. It reaches 3.9:1, which is large text only. Body links use green dark.
  • Amber is never used as a body text colour on cream (3.4:1). It is used as a fill, a rule, an icon or large text.
  • Slate is the lightest permitted text colour. Grey type below 5:1 does not appear anywhere in the platform.
  • No status is carried by colour alone. Every pill and marker pairs its colour with a text label and, where it signals restriction, an icon.

Status pills, and the only meanings they are allowed to carry

A badge in this platform always reports state. It is never a decorative label, never a category tag, and never a count. Hierarchy comes from type weight, size and spacing. The following six families are the only badges permitted anywhere on any surface. Anything not on this list is set as plain text.

  1. Document status: Draft, For Review, Final, Adopted, Superseded.
  2. Document confidentiality: Public, Member, Confidential, Secretariat.
  3. Submission state: Draft, Submitted, Validated, Returned.
  4. Meeting status: Scheduled, In Progress, Completed, Cancelled, Postponed.
  5. The comparator verified-data marker.
  6. Per-field translation status, in the administration translation editor only.

Sector, instrument type, committee, content type, year, file format and result counts are metadata. They are set as plain text, in slate, on one line. The demonstration-data warning is a notice component, not a badge, and appears once per screen rather than once per value.

Geometry lives once, in assets/sadc-geometry.js, and is rendered only by RegionMap.dc.html. The members screen mounts it in select mode, the comparator in choropleth mode. No screen holds its own copy of a country outline.
Rules the component enforces
  • Real geometry only. Natural Earth 1:110m for the mainland, 1:50m for the island and context states, one Mercator projection fitted to the region. Never a freehand outline.
  • Labels are an HTML layer over the SVG, sized in container units so they scale with the map. Interpolated text inside an SVG text element renders as an HTML span and produces no glyphs, so it is never used.
  • All fourteen member regulators are equally styled, equally selectable and equally keyboard reachable. Comoros and Mauritius sit in enlarged insets, labelled as such, because their true extent is under one pixel at regional scale.
  • SADC states without a CRASA regulator carry the neutral sand tone, are not focusable, and are named in the legend as context only.
  • Every state states its value as text as well as a shade, so nothing depends on colour alone.
07

Layout invariants

Binding. These are not per-screen decisions.
  1. Every flex wrapper that must shrink carries min-width:0.
    A flex item defaults to min-width:auto, which is its min-content width, so it refuses to shrink and pushes its siblings off screen. The failure is silent and only appears at narrow widths. This applies to intermediate wrappers as much as to leaves: if the wrapper cannot shrink, no reduction reaches the child that was supposed to truncate.
  2. flex:none only on elements that must never shrink.
    Currently that is the language switcher, icon buttons, avatars and the extranet action. Applying it to a container instead makes the row unshrinkable and causes the exact overflow it was meant to prevent.
  3. Truncating labels carry all three properties.
    overflow:hidden, text-overflow:ellipsis and white-space:nowrap, on a parent that has min-width:0. Any one of the four missing means no ellipsis.
  4. An input inside a flex row needs min-width:0.
    A text input carries an intrinsic width from its size attribute, around 240px by default. Inside a flex row with a unit suffix, that floor pushes the suffix outside the wrapper. Set min-width:0 on the input and flex:none;white-space:nowrap on the suffix.
  5. No fixed pixel grid column.
    A track written as 300px cannot shrink and sets a min-content floor for the whole page. Write it as minmax(0,300px), or as repeat(auto-fit,minmax(Npx,1fr)) where the columns should stack.
  6. Header rows carry flex-wrap:wrap as the floor.
    When shrinking runs out, wrapping to a second row is always better than a horizontal scrollbar.
  7. A wide table scrolls inside its own column, never over its neighbour.
    The wrapper gets min-width:0;overflow-x:auto, and side-by-side panels use repeat(auto-fit,minmax(Npx,1fr)) so they stack rather than collide.

Acceptance test, every screen

No horizontal overflow at any of these four widths, measured on a fresh reload rather than a live-edited render. A live render can report the previous layout and produce a false pass.

Why this section exists

Each of these rules is written down because it was found by a real defect: a clipped language switcher, a percentage unit pushed off screen, a comparison table painting over a chart, and a header that could not shrink. Stating them here means they are fixed once rather than per screen.

Motion and accessibility

Motion

Micro-interactions120 to 180ms
Element entrances300 to 400ms
Route transitions400 to 500ms
Absolute ceiling600ms
Permitted

Scroll reveals with a short stagger, count-up on statistics once per view, hero parallax to a maximum of 15 percent of scroll distance, comparator column transitions, chart draw-in on first view, map hover and selection, navigation state changes, skeletons instead of spinners, toasts, modal and drawer entrances, accordion and tab transitions, row hover.

Forbidden

Bouncing, spinning logos, typewriter text, floating particles, auto-playing carousels, hover effects that move layout, scroll-jacking, and anything that delays a user reaching content.

Reduced motion is honoured throughout. Under prefers-reduced-motion, movement stops but feedback does not: opacity and colour transitions remain, counters render at their final value, and every screen stays fully usable. No meaning in this platform is carried by motion or by hover alone.

Accessibility, WCAG 2.1 AA

  • Contrast. Every pairing in this document is measured and stated. Body text is 5:1 or better. Large text is 3:1 or better. Non-text controls and focus indicators are 3:1 or better against their adjacent colour.
  • Focus. A 3px amber ring at 2px offset on every interactive element. Focus order follows reading order. Nothing removes the outline.
  • Keyboard. Every flow completable without a pointer, including the comparator selection, the calendar, the translation editor and the data e-Form. Modals trap focus and return it. A skip link opens every page.
  • Structure. One h1 per page, headings in order, landmark regions, tables with scope on every header cell, form labels always present and never replaced by a placeholder.
  • Language. A lang attribute per rendered language, and per element where content falls back to English inside a translated page, so screen readers switch voice correctly.
  • Images. Alt text is a required field in all three languages. Decorative graphics such as the map motif are marked aria-hidden.
  • Targets. 44 by 44px minimum, on every surface and every breakpoint.
  • Independence. No information conveyed by colour alone, by hover alone, or by motion alone.
