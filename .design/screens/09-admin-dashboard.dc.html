Dark mode

The same dashboard, dark surface set

Static rendition. The panel below shows the dark surface set as a fixed illustration.

Dark mode is the same tokens with a different set of surface and ink values, not a second design. Contrast is measured the same way: body ink at 12.4:1 on the page ground, dimmed ink at 6.8:1, and the green raised to #2FA76F so it clears AA against the dark surface. The Secretariat sets it per account, and it follows the operating system by default.
